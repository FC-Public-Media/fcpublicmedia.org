# Brand assets for the screens in the building

Desktop backgrounds and an idle screen for the studio panels.

Not site content, and deliberately not inside `site/`. `site/` is the build
root, so anything in it is one `exclude:` entry away from a public URL —
`site/bin/` and `site/tests/` are exactly that, and three internal documents
reached the internet through a trusted exclude list once already. A sibling
directory cannot. These get to a machine by clone or download.

Generated by [`bin/make-wallpaper.py`](../bin/make-wallpaper.py), which
is the file to edit. The PNGs are committed because the machine that needs
them is a workstation, not a thing that runs a build.

---

## The tilt

The mark leans **counterclockwise**, −8°, always. Same angle as
`site/assets/img/icon.svg` and `.wordmark-mark` in the stylesheet.

The other direction is not a variant, it is the mistake. A square leaning back
reads as a clipboard clip lifting at its top edge; leaning forward it reads as
rolling forward, which is what the O in the Roblox wordmark does. There are
copies of our mark in the wild that got this backwards —
`site/assets/img/icon-inverted.svg` exists to correct one of them.
`bin/test_make_wallpaper.py` fails the build if the sign ever flips.

## What is here

One image of all five, so this is openable from a phone without downloading
ten files. Remake it after a change with:

```sh
magick wallpaper/tally-{1,2,3}-1050x1680.png -resize 420x672 \
  -bordercolor '#000000' -border 10 +append /tmp/desk.png
magick wallpaper/{plate,band}-1050x1680.png -resize 420x672 \
  -bordercolor '#000000' -border 10 +append /tmp/others.png
magick /tmp/desk.png /tmp/others.png -background '#3a3d42' -gravity center \
  -extent 1320x692 -append -bordercolor '#3a3d42' -border 20 preview.png
```


`wallpaper/` holds each design at `1050x1680` (a 1680×1050 panel rotated into
portrait, which is how the studio's are mounted) and at `1680x1050` for one
that has not been turned yet. SVG alongside each PNG; the SVG is the source.

| Design | What it is | Where it goes |
| --- | --- | --- |
| `plate` | One mark, one rule, one lockup. The quiet one. | Anywhere. The default if you only want one. |
| `tally-1`, `tally-2`, `tally-3` | Three marks in a column, a different one lit in each file. | The three panels, left to right. |
| `band` | The masthead across the top, then paper. The light one. | The panel by the door, the one that spends its day showing something. |

The tally set is the answer to three identical backgrounds reading as a tiling
accident. The lit square walks down the column as your eye crosses the desk,
and each file still reads as a deliberate mark standing on its own — which
matters, because monitors get rearranged and nobody will remember the order.

`plate` puts its composition low on purpose. Desktop icons stack down from the
top-left corner, so the top 40% is left empty and the wallpaper gets out of
the way of the thing the desktop is actually for.

## Putting them on the monitors

**Windows.** Settings → Personalization → Background. Set **Choose a fit** to
**Fill**, not Span — Span is what stretches one image across the whole desk,
which is what is happening now and why the mark lands in the gap between two
panels. Then add all three files, and in the **Recent images** strip
right-click each one → **Set for monitor 1 / 2 / 3**. That per-monitor menu is
the only way Windows does this; there is no setting for it.

**macOS.** System Settings → Wallpaper. Each display gets its own section on
that screen. Fit: **Fill Screen**.

If a panel is still landscape, use the `1680x1050` file for it.

## Other resolutions

Every measurement in the generator is a fraction of the canvas, so a new panel
is an argument rather than a redraw:

```sh
python3 bin/make-wallpaper.py --size 2160x3840
python3 bin/make-wallpaper.py --size 3840x2160 --design plate --no-text
```

`--no-text` drops the lockup and leaves the mark alone. A desktop does not
need to be told whose it is every time somebody looks at it.

Rendering the PNGs needs `rsvg-convert` (`brew install librsvg`). Without it
the script still writes the SVGs and says so.

## The idle screen

[`idle/index.html`](idle/index.html) — open it in any browser on the panel and
press <kbd>F11</kbd> (macOS: <kbd>⌃⌘F</kbd>). The lit square walks the column
and a clock sits at the bottom. That is all it does.

Deliberately not a screensaver bundle. A `.saver` is macOS-only, a `.scr` is
Windows-only, both want signing, and neither can be changed without walking to
the machine. One HTML file means the thing on the wall is the thing in the
repository. No dependencies and no network, so it comes up on a machine that
has been off for a month and has not joined the wifi yet.

It has a marked slot for live content — the guest network, a check-in prompt,
what is on air. Empty, the slot collapses and the screen is just the brand,
which is the right thing for a panel with nothing to say. For something
temporary, put it on the URL:

```
idle/index.html?say=Back at 2pm
```

For anything recurring, write into `#slot` properly. Keep it to one idea; it
is read from across a room by somebody walking past.
