Above `<rect width="64" height="64" rx="10" fill="#ffc61a"/>`

The mark with the colour system inverted: the plate becomes the field, and
the square becomes the pure black that the slate only gestures at.

SAME TILT AS EVERY OTHER VERSION — counterclockwise, -8deg. That is the
correction this file exists to make. The variant currently on the GitHub
org leans the other way, and a square leaning forward reads as rolling
forward, which is what Roblox's logo does with the O in its wordmark. This
one is meant to read as a clipboard clip, lifting at the top edge, which
only works leaning back.

Not referenced by any page. It is for the places a square avatar sits on
somebody else's chrome — the GitHub org, a social profile — where the dark
plate of icon.svg disappears into a dark UI and the yellow needs to be the
thing you see.
