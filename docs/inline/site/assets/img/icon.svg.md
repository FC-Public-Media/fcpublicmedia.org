## 1

Above `<rect width="64" height="64" rx="10" fill="#121417"/>`

The same mark the masthead draws in CSS: a solid square set askew, like a
tally light. A square set straight reads as a bullet point; a square set
askew reads as a mark somebody chose. Same -8deg, same #ffc61a.

It sits on the masthead's own #121417 rather than on transparency, because
a favicon has no control over the colour behind it and yellow on a white
tab strip is close to invisible. The dark plate is what makes it legible
on light and dark browser chrome alike.

64x64 with a viewBox, so this one file is the 16px favicon, the 180px
touch icon and anything else that gets asked for.
