## 1

Above `{% include class-config.html %}`

Two audiences at once. Whoever is holding the phone taps the button. Whoever
is standing next to them scans the code. Both land in the same place.

The QR is the same committed SVG the printed poster uses, so there is one
code in the world rather than two that could drift apart.

When a class is running, assets/js/classmode.js unhides the class block
above it — from data baked in at build time, with no request made. Outside
class hours the block stays hidden and this is an ordinary check-in card.
