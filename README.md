# librarians

A branch of FCPM's library, never merged into `main`: what librarian agents answer to. Instructions,
never data. The library's code reads no files; librarians do, because they are its caretakers, and so
they answer to the constitution here and to each place's decorum.

- `CONSTITUTION.md`: what every librarian does, and never does.
- `<holding>/AGENTS.md`: a place's decorum. Why things are there at all, and what they are for. Written
  per place, never per item, in the place's own folder shape; a folder gets its own `AGENTS.md` only
  where it needs one.

Holdings are named in `library.yml` on `main`; where each sits on a machine is `fcpm library where`.
What librarians write goes to the machine's `retain/<machine>` branch, which never leaves the media
node's LAN. Nothing here names a person. See `docs/library.md` on `main`.
