# For the Spanish reader

Thank you for reading this. Fort Collins Public Media's website has a Spanish version that a computer
wrote. Nobody who speaks Spanish has read it yet. Until someone does, a phone set to Spanish still gets
English.

**How to read it.** Each line below is an English sentence from the site and the Spanish that stands in for
it. If the Spanish is right, put ✓ in the last column. If not, write what you would say. To see a line in
place, open fcpublicmedia.org (once it is deployed) and press **Español** at the bottom of any page.

**Keep it as short as the English.** The site is written plainly on purpose: short sentences, each saying
one thing. Spanish that is polite but longer is worse here than Spanish that is blunt.

**Four questions first:**

1. **Tú or usted?** It uses tú throughout, to match the site's voice ("Don't Just View It. Do It.").
2. **Which Spanish?** Our neighbours in Fort Collins, mostly. Say if a word reads as from somewhere else.
3. **The slogans.** "You are PUBLIC MEDIA." is now "Los MEDIOS PÚBLICOS eres tú.", and "Don't Just View
   It. Do It." is now "No solo lo veas. ¡Hazlo!". Would you translate them at all, or leave them in English?
4. **Words for people.** Board titles are written as offices ("Presidencia", "Tesorería") and the welcome as
   "Te damos la bienvenida", so that nothing guesses anyone's gender. Does that read naturally?

When you are done, whoever set this up changes one line (`follow_device: true` in
`site/_data/strings/es.yml`), and phones set to Spanish start getting Spanish.

Names (FC Public Media, Comcast 97, YouTube), addresses, email addresses, and program titles from our
channel stay as they are.
