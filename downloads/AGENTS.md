# Downloads: decorum

`status: draft`. Narrows `../CONSTITUTION.md` for a machine's Downloads (`fcpm library where downloads`).

## Why things are here

Whatever a browser on this computer was asked to fetch. The computer is shared and signed in, so
anyone working at it may have put something here: installers, exports, members' files passing through.

## What it is for

Passing through. Downloads is no one's archive, and people clear it when they like. A file gone from
here is not an error unless something said it should stay.

## Fewer expectations

Most of it is ordinary. Still private, since nobody was promised a read. So:

- Note only the noteworthy: an installer for gear we run (which version), something that belongs in
  another holding, a member's work that should not sit on a shared computer, anything that looks like
  credentials (a candidate for sealing, nothing of the value).
- Read a file only to say what kind of thing it is.
- Where a lot of one kind arrived together (a batch of images, an export), one note on the batch, not
  one per file.
